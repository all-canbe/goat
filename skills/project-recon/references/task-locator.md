# 任务定位查询

<!-- @类型: 参考指南 -->
<!-- @目的: 提供基于报告的任务 → 代码定位方法 -->

> 本文档不负责工作流路由。

## 前提条件

必须先有 `project-recon-report.md`，才能进行任务定位查询。若报告不存在，提示用户先运行项目侦察。

## 查询流程

### 1. 读取报告

- 读取 `project-recon-report.md`
- 重点解析"模块地图"章节（第 3 章）

### 2. 解析任务描述

从用户输入中提取：

| 维度 | 示例 | 用途 |
|------|------|------|
| 动作类型 | 新增、修改、删除、修复 | 判断变更类型 |
| 业务实体 | 用户、订单、支付 | 匹配模块名/职责 |
| 技术层面 | UI、接口、数据库 | 过滤文件类型 |
| 功能关键词 | 登录、购物车、VIP | 精确匹配模块 |

### 3. 匹配模块

按优先级匹配：

1. **精确匹配**：关键词 = 模块名
2. **语义匹配**：关键词 ≈ 模块职责描述
3. **路径匹配**：关键词出现在文件路径中
4. **依赖链匹配**：通过已匹配模块的 import 关系扩展

### 4. 定位文件

- 在匹配模块的关键文件中逐一检查
- 读取文件头部确认关联度
- 分析 import 关系发现关联文件

### 5. 输出结果

```markdown
## 任务定位结果

**任务**: {用户输入}
**匹配模块**: {模块名}

### 建议查看的文件
1. `{路径}` — {原因}
2. `{路径}` — {原因}

### 影响范围
- {受影响的模块/文件}

### 注意事项
- {项目约定/规则}
```
