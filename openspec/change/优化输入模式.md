# 优化输入交互模式

## 变更内容

### 1. 新增 Agent/命令双模式切换 (`/mode`)

- 添加了 `agent_mode` 属性，默认值为 `True`
- 新增 `/mode` 命令，支持在 Agent 模式和命令模式间自由切换

### 2. Agent 模式（默认）— 直接输入即对话

- 启动后默认进入 Agent 模式，无需输入 `/chat` 前缀
- 任何不以 `/` 开头的输入直接作为聊天消息发送给主 Agent
- 提示符显示为 `🤖 >`

### 3. 命令模式 — 传统命令操作

- 通过 `/mode` 切换到命令模式，提示符变为 `🔧 >`
- 命令模式下所有输入均视为命令，便于执行 `/spawn`、`/list` 等管理操作
- 输入 `/mode` 可切换回 Agent 模式

### 4. 更新帮助信息

- HELP_TEXT 中添加了模式说明和 `/mode` 命令文档

## 修改的文件

- `main.py` — 添加模式切换逻辑、修改输入循环、更新提示符和帮助文本

## 修改意义

- **降低使用门槛**：用户无需记住 `/chat` 前缀，像普通聊天工具一样直接输入即可
- **提升效率**：减少不必要的命令前缀输入，对话更自然流畅
- **灵活性**：通过 `/mode` 随时切换，兼顾聊天交互和命令管理两种场景
