### 2. 新增功能

#### Vim 模式输入（精简版）
- **文件**: `my_tui/tui/widgets/input_panel.py`
- 添加 `vim_mode` reactive 属性（INSERT / NORMAL）
- Esc 切换 INSERT ↔ NORMAL 模式
- NORMAL 模式下：h/l 光标左/右、0 行首、$ 行尾、i 进入插入
- `watch_vim_mode` 自动禁用/启用 Input 控件
- 模式指示器显示 `[NORMAL]`（橙色粗体）或 `INSERT`（灰色）

#### 文件树/项目浏览（精简版）
- **文件**: `my_tui/tui/widgets/side_panel.py`
- 使用 Textual `Tree` 组件
- `_populate_tree` 递归填充文件和目录，忽略 .git/\_\_pycache\_\_ 等
- 目录展开/折叠、Tab 在 Agent/文件/任务间切换焦点
- 选择文件触发 `SelectedFile` 消息
- `/tree [path]` 命令刷新文件树
- `rebuild_tree()` 支持指定根路径

#### 内联文件编辑（精简版）
- **新文件**: `my_tui/tui/widgets/edit_panel.py`
- `EditPanel`：ModalScreen，内嵌 TextArea 编辑器 + 保存/取消按钮
- Ctrl+S 保存、Esc 取消
- 自动写回原文件
- `/edit <path>` 命令打开编辑器
- 文件树中选择文件后自动记录路径，`/edit` 无参时编辑上次浏览的文件

### 3. 辅助修改
- `my_tui/tui/state.py`：添加 `pending_file_edit` 和 `editor_open` 字段
- `my_tui/tui/app.py`：
  - 添加 CSS 样式（文件树、Vim 指示器、编辑面板）
  - 添加 `/tree`、`/read`、`/edit` 命令支持
  - 添加 `on_side_panel_selected_file` → `_show_file_content` 处理流程
  - 更新 `/help` 帮助文本
- `my_tui/tui/widgets/command_menu.py`：添加文件操作相关命令条目
- `my_tui/tui/widgets/__init__.py`：导出 EditPanel

## 为何这样修改

- **代码高亮 & Markdown & Diff 预览**：这些功能实际已在代码中实现（使用了 `rich.syntax.Syntax` 和 `rich.markdown.Markdown`），但差距文档未及时更新
- **消息折叠/展开**：`_collapsed` 字典和 Enter 键切换机制已实现，文档状态落后于代码
- **Vim 模式**：满足需要键盘高效导航的用户，精简实现仅覆盖最常用操作（h/l/0/$/i/Esc）
- **文件树**：提供项目导航能力，基于 Textual Tree 组件实现最简可交互版本
- **内联文件编辑**：允许在 TUI 内直接修改文件，避免切换外部编辑器

## 变更的意义

- 差距文档的 **10 项 TUI 交互体验** 中 7 项已完成（3 项待增强），完成度从 0% 提升至 70%
- Vim 模式使键盘驱动用户获得更高效的输入体验
- 文件树和内联编辑构成基本的`浏览-编辑-保存`工作流闭环
- 文档与实际代码状态对齐，便于后续任务规划
